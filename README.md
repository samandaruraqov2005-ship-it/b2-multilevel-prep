# B2 Multilevel tayyorlov

Daraja testi + har kuni 5 ko'nikma (lug'at, reading, listening, writing, speaking) + qat'iy tekshiruv.

## Render sozlamalari
- Build command: `npm install`
- Start command: `node server.js`
- Environment: `ANTHROPIC_API_KEY` (majburiy), `MODEL` (ixtiyoriy, default `claude-sonnet-5-5`), `APP_SECRET` (ixtiyoriy, tasodifiy matn)

## O'tish qoidasi
Har bir blok >= 60%, o'rtacha >= 70%. Keyingi kun faqat ertasi kuni ochiladi.
Progress brauzer localStorage'da saqlanadi (bitta qurilma).
